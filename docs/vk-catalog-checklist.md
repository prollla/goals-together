# Подготовка к каталогу VK Mini Apps

Требования модерации меняются — перед отправкой сверьтесь с актуальными правилами на
[dev.vk.com](https://dev.vk.com/ru/mini-apps/) (разделы о размещении в каталоге и модерации).

## Уже сделано в коде

- [x] Подпись launch-параметров проверяется на сервере (`VK_APP_SECRET`), пользователя нельзя подменить.
- [x] Экран «О приложении и данных»: какие данные хранятся, контакт поддержки, кнопка «Удалить мои данные»
      (удаляет всё на сервере, общие цели переходят друзьям).
- [x] Светлая и тёмная темы VK, мобильная и desktop-вёрстка (боковая панель на vk.com).
- [x] Работа без VK-профиля не ломает приложение; ошибки сервера показываются по-русски.
- [x] Уведомления только после явного разрешения пользователя (`VKWebAppAllowNotifications`).
- [x] Шаринг через VK: ссылка (`VKWebAppShare`), приглашение друга (`VKWebAppShowRequestBox`),
      история (`VKWebAppShowStoryBox`).

## Нужно сделать вам

1. **Заполнить `src/config.ts`:**
   - `SUPPORT_URL` — сообщество или страница поддержки;
   - `OPERATOR_NAME` — кто отвечает за данные (ФИО/название);
   - `PRIVACY_POLICY_URL` — ссылка на полную политику (шаблон: `docs/privacy-policy.md`).
2. **Опубликовать политику конфиденциальности** по постоянной ссылке (например, статья в сообществе VK)
   и указать её в настройках приложения в VK.
3. **Оформление в настройках приложения VK:** название, короткое и полное описание, категория,
   иконка и скриншоты (размеры — по актуальным требованиям на dev.vk.com).
   Удобно снять скриншоты экранов «Сегодня», «Мои цели», «Группа» и «Достижения» в светлой теме.
4. **Сервисный ключ** (`VK_SERVICE_KEY` на сервере) — для проверенных имён и уведомлений.
5. **Проверить на всех платформах:** iOS, Android, m.vk.com, vk.com (desktop) — запуск, создание цели,
   отметка, приглашение друга, история, переключатель напоминаний, тёмная тема.
6. **Проверить приглашение через запрос VK:** отправьте запрос другу (кнопка «Пригласить друга из VK»
   в «Группе») и убедитесь, что он попадает на экран приглашения. Приложение ищет ключ `goal-<id>`
   в параметрах `request_key` / `vk_request_key` и в hash; если VK передаёт его иначе — напишите, поправлю.
7. **Отправить на модерацию** в настройках приложения.

## После публикации

- Следить за доступностью API (например, UptimeRobot на `https://94.228.170.88.sslip.io/api/health`).
- Забирать резервные копии из `./backups` на другой компьютер.
